# SignalSentinel — judge-facing command flow

Run **every command yourself** in cmd, in this order. Each one is a single
copy-paste line (cmd has no `\` line continuations). After each command,
say the highlighted beat, then advance.

Estimated total: **~2 minutes**. Everything runs on **real live data**.

---

## Part A — Install & first target (~30s)

```bat
npm install -g signal-sentinel
```

> "Installed from npm in one command — `sentinel` is now on PATH, with webcmd as the browser runtime."

```bat
sentinel init
```

> "Creates the config and state directory."

```bat
sentinel target add acme-pricing --site coingecko --command top --watch price,marketCap --key symbol -- --limit 10
```

> "This is the whole product in one line: **watch a real site** (CoinGecko's top-10 coins),
> **which fields** (price, market cap), keyed by symbol. Everything after `--` passes to
> webcmd — no quoting pain."

```bat
sentinel target list
```

> "The library of learned commands — this grows into a compounding asset."

---

## Part B — The watch loop (~30s)

```bat
sentinel watch acme-pricing
```

> "**First run: explore once.** Sentinel has webcmd browse the site, understand its
> structure, and compile a fast reusable command. Baseline captured."

```bat
sentinel watch acme-pricing
```

> "**Second run: reuse.** The compiled command runs sub-second. Sentinel diffs the live
> surface against the baseline and reports material change — no string diffs, no noise."

---

## Part C — The intelligence layer (~40s)

```bat
sentinel diff acme-pricing
```

> "Inspect the raw diff — read-only, doesn't update the baseline."

```bat
sentinel status
```

> "Library health across all targets — and look, **4 of them are 'changed' right now**.
> That's real movement on live sites (Product Hunt, GitHub Trending, Hugging Face, npm)."

```bat
sentinel history ph-today
```

> "Every run is audited — a timestamped trail of clean/changed/critical."

```bat
sentinel brief ph-today
```

> "**The money shot.** A plain-language brief generated by Groq from the actual diff:
> what changed, what it likely means, what to do next. This is the layer that turns raw
> signals into a decision — competitor intelligence, not a price ticker."

---

## Part D — Ops & self-healing (~30s)

```bat
sentinel run
```

> "Force-run every target at once — watch the live signals fire across all of them."

```bat
sentinel state
```

> "Everything is plain JSON/JSONL on disk — git-trackable, inspectable, no hidden state."

```bat
sentinel repair acme-pricing
```

> "**The self-healing loop.** If a watched site changes its structure, the command breaks.
> Sentinel detects it, attempts autonomous repair, and only escalates to a human with an
> exact protocol. The library keeps itself alive."

```bat
sentinel daemon --force
```

> "Continuous monitoring — runs on each target's cadence. Ctrl-C to stop."

*(press Ctrl-C)*
